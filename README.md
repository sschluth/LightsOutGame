# LightsOutGame

A Java implementation of the Lights Out puzzle with a GUI and interactive 5x5 game board.

## Features

* Interactive 5x5 Lights Out game board
* Clicking a light toggles the selected light and its neighboring lights
* Randomized starting board
* Manual setup mode for creating custom board configurations
* Detects when the puzzle has been solved
* Uses graphical icons to display light states

## Technologies

* Java
* Swing
* Object-Oriented Programming
* Event Handling

## Project Structure

* `LightsOutProgram.java` - Starts the game
* `LightsOutFrame.java` - Creates the game window, board, controls, and game logic
* `LightsOutButton.java` - Represents individual lights and manages their states
* `light_on.png` / `light_off.png` - Images used to display the light states
